# B2bi Service



**Resources**: 2

---

## Overview

The b2bi service provides access to 2 resource types:

- [Starter_mapping_template](#starter_mapping_template) [C]
- [Transformer_job](#transformer_job) [R]

---

## Resources


### Starter_mapping_template

StarterMappingTemplate resource

**Operations**: ✅ Create

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `template_details` | String | ✅ | <p> Describes the details needed for generating the template. Specify the X12 transaction set and version for which the template is used: currently, we only support X12. </p> |
| `mapping_type` | String | ✅ | <p>Specify the format for the mapping template: either JSONATA or XSLT.</p> |
| `output_sample_location` | String |  | <p>Specify the location of the sample EDI file that is used to generate the mapping template.</p> |



#### Usage Example

```kcl
# main.k
import aws

# Initialize provider
provider = aws.AwsProvider {
    region = "us-east-1"
}

# Create starter_mapping_template
starter_mapping_template = provider.b2bi.Starter_mapping_template {
    template_details = "value"  # <p> Describes the details needed for generating the template. Specify the X12 transaction set and version for which the template is used: currently, we only support X12. </p>
    mapping_type = "value"  # <p>Specify the format for the mapping template: either JSONATA or XSLT.</p>
}

```

### Transformer_job

TransformerJob resource

**Operations**: ✅ Read

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|


#### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `message` | String | <p>Returns an optional error message, which gets populated when the job is not run successfully.</p> |
| `status` | String | <p>Returns the current state of the transformer job, either <code>running</code>, <code>succeeded</code>, or <code>failed</code>.</p> |
| `output_files` | Vec<String> | <p>Returns the location for the output files. If the caller specified a directory for the output, then this contains the full path to the output file, including the file name generated by the service.</p> |


#### Usage Example

```kcl
# main.k
import aws

# Initialize provider
provider = aws.AwsProvider {
    region = "us-east-1"
}

# Access transformer_job outputs
transformer_job_id = transformer_job.id
transformer_job_message = transformer_job.message
transformer_job_status = transformer_job.status
transformer_job_output_files = transformer_job.output_files
```

## Common Operations

### Creating Multiple Resources

```kcl
import aws

provider = aws.AwsProvider {
    region = "us-east-1"
}

# Create multiple starter_mapping_template resources
starter_mapping_template_0 = provider.b2bi.Starter_mapping_template {
    template_details = "value-0"
    mapping_type = "value-0"
}
starter_mapping_template_1 = provider.b2bi.Starter_mapping_template {
    template_details = "value-1"
    mapping_type = "value-1"
}
starter_mapping_template_2 = provider.b2bi.Starter_mapping_template {
    template_details = "value-2"
    mapping_type = "value-2"
}
```

### Conditional Creation

```kcl
# Only create in production
if environment == "production":
    starter_mapping_template = provider.b2bi.Starter_mapping_template {
        template_details = "production-value"
        mapping_type = "production-value"
    }
```

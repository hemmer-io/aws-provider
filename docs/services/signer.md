# Signer Service



**Resources**: 4

---

## Overview

The signer service provides access to 4 resource types:

- [Signing_platform](#signing_platform) [R]
- [Signing_job](#signing_job) [R]
- [Signing_profile](#signing_profile) [CR]
- [Revocation_status](#revocation_status) [R]

---

## Resources


### Signing_platform

SigningPlatform resource

**Operations**: ✅ Read

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|


#### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `platform_id` | String | <p>The ID of the target signing platform.</p> |
| `target` | String | <p>The validation template that is used by the target signing platform.</p> |
| `signing_configuration` | String | <p>A list of configurations applied to the target platform at signing.</p> |
| `revocation_supported` | bool | <p>A flag indicating whether signatures generated for the signing platform can be
			revoked.</p> |
| `display_name` | String | <p>The display name of the target signing platform.</p> |
| `partner` | String | <p>A list of partner entities that use the target signing platform.</p> |
| `category` | String | <p>The category type of the target signing platform.</p> |
| `max_size_in_mb` | i64 | <p>The maximum size (in MB) of the payload that can be signed by the target
			platform.</p> |
| `signing_image_format` | String | <p>The format of the target platform's signing image.</p> |


#### Usage Example

```kcl
# main.k
import aws

# Initialize provider
provider = aws.AwsProvider {
    region = "us-east-1"
}

# Access signing_platform outputs
signing_platform_id = signing_platform.id
signing_platform_platform_id = signing_platform.platform_id
signing_platform_target = signing_platform.target
signing_platform_signing_configuration = signing_platform.signing_configuration
signing_platform_revocation_supported = signing_platform.revocation_supported
signing_platform_display_name = signing_platform.display_name
signing_platform_partner = signing_platform.partner
signing_platform_category = signing_platform.category
signing_platform_max_size_in_mb = signing_platform.max_size_in_mb
signing_platform_signing_image_format = signing_platform.signing_image_format
```

### Signing_job

SigningJob resource

**Operations**: ✅ Read

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|


#### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `signing_parameters` | HashMap<String, String> | <p>Map of user-assigned key-value pairs used during signing. These values contain any
			information that you specified for use in your signing job. </p> |
| `platform_display_name` | String | <p>A human-readable name for the signing platform associated with the signing job.</p> |
| `profile_version` | String | <p>The version of the signing profile used to initiate the signing job.</p> |
| `platform_id` | String | <p>The microcontroller platform to which your signed code image will be
			distributed.</p> |
| `requested_by` | String | <p>The IAM principal that requested the signing job.</p> |
| `status` | String | <p>Status of the signing job.</p> |
| `job_owner` | String | <p>The AWS account ID of the job owner.</p> |
| `completed_at` | String | <p>Date and time that the signing job was completed.</p> |
| `status_reason` | String | <p>String value that contains the status reason.</p> |
| `overrides` | String | <p>A list of any overrides that were applied to the signing operation.</p> |
| `signature_expires_at` | String | <p>Thr expiration timestamp for the signature generated by the signing job.</p> |
| `profile_name` | String | <p>The name of the profile that initiated the signing operation.</p> |
| `revocation_record` | String | <p>A revocation record if the signature generated by the signing job has been revoked.
			Contains a timestamp and the ID of the IAM entity that revoked the signature.</p> |
| `created_at` | String | <p>Date and time that the signing job was created.</p> |
| `job_id` | String | <p>The ID of the signing job on output.</p> |
| `signed_object` | String | <p>Name of the S3 bucket where the signed code image is saved by AWS Signer.</p> |
| `job_invoker` | String | <p>The IAM entity that initiated the signing job.</p> |
| `signing_material` | String | <p>The Amazon Resource Name (ARN) of your code signing certificate.</p> |
| `source` | String | <p>The object that contains the name of your S3 bucket or your raw code.</p> |

signing_job_platform_display_name = signing_job.platform_display_name
signing_job_profile_version = signing_job.profile_version
signing_job_platform_id = signing_job.platform_id
signing_job_requested_by = signing_job.requested_by
signing_job_status = signing_job.status
signing_job_job_owner = signing_job.job_owner
signing_job_completed_at = signing_job.completed_at
signing_job_status_reason = signing_job.status_reason
signing_job_overrides = signing_job.overrides
signing_job_signature_expires_at = signing_job.signature_expires_at
signing_job_profile_name = signing_job.profile_name
signing_job_revocation_record = signing_job.revocation_record
signing_job_created_at = signing_job.created_at
signing_job_job_id = signing_job.job_id
signing_job_signed_object = signing_job.signed_object
signing_job_job_invoker = signing_job.job_invoker
signing_job_signing_material = signing_job.signing_material

### Signing_profile

SigningProfile resource

**Operations**: ✅ Create ✅ Read

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `profile_name` | String | ✅ | <p>The name of the signing profile to be created.</p> |
| `signature_validity_period` | String |  | <p>The default validity period override for any signature generated using this signing
			profile. If unspecified, the default is 135 months.</p> |
| `overrides` | String |  | <p>A subfield of <code>platform</code>. This specifies any different configuration
			options that you want to apply to the chosen platform (such as a different
				<code>hash-algorithm</code> or <code>signing-algorithm</code>).</p> |
| `tags` | HashMap<String, String> |  | <p>Tags to be associated with the signing profile that is being created.</p> |
| `platform_id` | String | ✅ | <p>The ID of the signing platform to be created.</p> |
| `signing_material` | String |  | <p>The AWS Certificate Manager certificate that will be used to sign code with the new signing
			profile.</p> |
| `signing_parameters` | HashMap<String, String> |  | <p>Map of key-value pairs for signing. These can include any information that you want to
			use during signing.</p> |


#### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `status` | String | <p>The status of the target signing profile.</p> |
| `revocation_record` | String |  |
| `status_reason` | String | <p>Reason for the status of the target signing profile.</p> |
| `profile_name` | String | <p>The name of the target signing profile.</p> |
| `signature_validity_period` | String |  |
| `arn` | String | <p>The Amazon Resource Name (ARN) for the signing profile.</p> |
| `profile_version_arn` | String | <p>The signing profile ARN, including the profile version.</p> |
| `tags` | HashMap<String, String> | <p>A list of tags associated with the signing profile.</p> |
| `profile_version` | String | <p>The current version of the signing profile.</p> |
| `signing_material` | String | <p>The ARN of the certificate that the target profile uses for signing operations.</p> |
| `platform_id` | String | <p>The ID of the platform that is used by the target signing profile.</p> |
| `platform_display_name` | String | <p>A human-readable name for the signing platform associated with the signing
			profile.</p> |
| `overrides` | String | <p>A list of overrides applied by the target signing profile for signing
			operations.</p> |
| `signing_parameters` | HashMap<String, String> | <p>A map of key-value pairs for signing operations that is attached to the target signing
			profile.</p> |


#### Usage Example

```kcl
# main.k
import aws

# Initialize provider
provider = aws.AwsProvider {
    region = "us-east-1"
}

# Create signing_profile
signing_profile = provider.signer.Signing_profile {
    profile_name = "value"  # <p>The name of the signing profile to be created.</p>
    platform_id = "value"  # <p>The ID of the signing platform to be created.</p>
}

# Access signing_profile outputs
signing_profile_id = signing_profile.id
signing_profile_status = signing_profile.status
signing_profile_revocation_record = signing_profile.revocation_record
signing_profile_status_reason = signing_profile.status_reason
signing_profile_profile_name = signing_profile.profile_name
signing_profile_signature_validity_period = signing_profile.signature_validity_period
signing_profile_arn = signing_profile.arn
signing_profile_profile_version_arn = signing_profile.profile_version_arn
signing_profile_tags = signing_profile.tags
signing_profile_profile_version = signing_profile.profile_version
signing_profile_signing_material = signing_profile.signing_material
signing_profile_platform_id = signing_profile.platform_id
signing_profile_platform_display_name = signing_profile.platform_display_name
signing_profile_overrides = signing_profile.overrides
signing_profile_signing_parameters = signing_profile.signing_parameters
```

## Common Operations

### Creating Multiple Resources

```kcl
import aws

provider = aws.AwsProvider {
    region = "us-east-1"
}

# Create multiple signing_platform resources
signing_platform_0 = provider.signer.Signing_platform {
}
signing_platform_1 = provider.signer.Signing_platform {
}
signing_platform_2 = provider.signer.Signing_platform {
}
```

### Conditional Creation

```kcl
# Only create in production
if environment == "production":
    signing_platform = provider.signer.Signing_platform {
    }
```

# Redshift_data Service



**Resources**: 4

---

## Overview

The redshift_data service provides access to 4 resource types:

- [Statement](#statement) [R]
- [Statement_result_v2](#statement_result_v2) [R]
- [Table](#table) [R]
- [Statement_result](#statement_result) [R]

---

## Resources


### Statement

Statement resource

**Operations**: ✅ Read

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|


#### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `secret_arn` | String | <p>The name or Amazon Resource Name (ARN) of the secret that enables access to the database. </p> |
| `updated_at` | String | <p>The date and time (UTC) that the metadata for the SQL statement was last updated. An
      example is the time the status last changed. </p> |
| `error` | String | <p>The error message from the cluster if the SQL statement encountered an error while running. </p> |
| `result_size` | i64 | <p>The size in bytes of the returned results. A <code>-1</code> indicates the value is null.</p> |
| `db_user` | String | <p>The database user name. </p> |
| `session_id` | String | <p>The session identifier of the query.</p> |
| `status` | String | <p>The status of the SQL statement being described. Status values are defined as follows: </p>
         <ul>
            <li>
               <p>ABORTED - The query run was stopped by the user. </p>
            </li>
            <li>
               <p>ALL -  A status value that includes all query statuses. This value can be used to filter results. </p>
            </li>
            <li>
               <p>FAILED - The query run failed. </p>
            </li>
            <li>
               <p>FINISHED - The query has finished running. </p>
            </li>
            <li>
               <p>PICKED - The query has been chosen to be run. </p>
            </li>
            <li>
               <p>STARTED - The query run has started. </p>
            </li>
            <li>
               <p>SUBMITTED - The query was submitted, but not yet processed. </p>
            </li>
         </ul> |
| `created_at` | String | <p>The date and time (UTC) when the SQL statement was submitted to run. </p> |
| `has_result_set` | bool | <p>A value that indicates whether the statement has a result set. The result set can be empty. The value is true for an empty result set.
      The value is true if any substatement returns a result set.</p> |
| `result_format` | String | <p>The data format of the result of the SQL statement.</p> |
| `id` | String | <p>The identifier of the SQL statement described. This value is a universally unique identifier (UUID) generated by Amazon Redshift Data API. </p> |
| `query_string` | String | <p>The SQL statement text. </p> |
| `duration` | i64 | <p>The amount of time in nanoseconds that the statement ran. </p> |
| `query_parameters` | Vec<String> | <p>The parameters for the SQL statement.</p> |
| `sub_statements` | Vec<String> | <p>The SQL statements from a multiple statement run.</p> |
| `redshift_query_id` | i64 | <p>The identifier of the query generated by Amazon Redshift. 
      These identifiers are also available in the <code>query</code> column of the <code>STL_QUERY</code> system view. </p> |
| `workgroup_name` | String | <p>The serverless workgroup name or Amazon Resource Name (ARN).</p> |
| `database` | String | <p>The name of the database. </p> |
| `cluster_identifier` | String | <p>The cluster identifier. </p> |
| `result_rows` | i64 | <p>Either the number of rows returned from the SQL statement or the number of rows affected.
        If result size is greater than zero, the result rows can be the number of rows affected by SQL statements such as INSERT, UPDATE, DELETE, COPY, and others. 
        A <code>-1</code> indicates the value is null.</p> |
| `redshift_pid` | i64 | <p>The process identifier from Amazon Redshift. </p> |


#### Usage Example

```kcl
# main.k
import aws

# Initialize provider
provider = aws.AwsProvider {
    region = "us-east-1"
}

# Access statement outputs
statement_id = statement.id
statement_secret_arn = statement.secret_arn
statement_updated_at = statement.updated_at
statement_error = statement.error
statement_result_size = statement.result_size
statement_db_user = statement.db_user
statement_session_id = statement.session_id
statement_status = statement.status
statement_created_at = statement.created_at
statement_has_result_set = statement.has_result_set
statement_result_format = statement.result_format
statement_id = statement.id
statement_query_string = statement.query_string
statement_duration = statement.duration
statement_query_parameters = statement.query_parameters
statement_sub_statements = statement.sub_statements
statement_redshift_query_id = statement.redshift_query_id
statement_workgroup_name = statement.workgroup_name
statement_database = statement.database
statement_cluster_identifier = statement.cluster_identifier
statement_result_rows = statement.result_rows
statement_redshift_pid = statement.redshift_pid
```

### Statement_result_v2

StatementResultV2 resource

**Operations**: ✅ Read

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|


#### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `records` | Vec<String> | <p>The results of the SQL statement in CSV format.</p> |
| `total_num_rows` | i64 | <p>The total number of rows in the result set returned from a query. 
      You can use this number to estimate the number of calls to the <code>GetStatementResultV2</code> operation needed to page through the results. </p> |
| `column_metadata` | Vec<String> | <p>The properties (metadata) of a column.</p> |
| `result_format` | String | <p>The data format of the result of the SQL statement.</p> |
| `next_token` | String | <p>A value that indicates the starting point for the next set of response records in a subsequent request. If a value is returned in a response, you can retrieve the next set of records by providing this returned NextToken value in the next NextToken parameter and retrying the command. If the NextToken field is empty, all response records have been retrieved for the request. </p> |


#### Usage Example

```kcl
# main.k
import aws

# Initialize provider
provider = aws.AwsProvider {
    region = "us-east-1"
}

# Access statement_result_v2 outputs
statement_result_v2_id = statement_result_v2.id
statement_result_v2_records = statement_result_v2.records
statement_result_v2_total_num_rows = statement_result_v2.total_num_rows
statement_result_v2_column_metadata = statement_result_v2.column_metadata
statement_result_v2_result_format = statement_result_v2.result_format
statement_result_v2_next_token = statement_result_v2.next_token
```

}

}

    }

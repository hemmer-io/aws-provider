# Ivschat Service



**Resources**: 4

---

## Overview

The ivschat service provides access to 4 resource types:

- [Logging_configuration](#logging_configuration) [CRUD]
- [Message](#message) [D]
- [Room](#room) [CRUD]
- [Chat_token](#chat_token) [C]

### Logging_configuration

LoggingConfiguration resource

**Operations**: ✅ Create ✅ Read ✅ Update ✅ Delete

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `destination_configuration` | String | ✅ | <p>A complex type that contains a destination configuration for where chat content will be
         logged. There can be only one type of destination (<code>cloudWatchLogs</code>,
            <code>firehose</code>, or <code>s3</code>) in a
         <code>destinationConfiguration</code>.</p> |
| `name` | String |  | <p>Logging-configuration name. The value does not need to be unique.</p> |
| `tags` | HashMap<String, String> |  | <p>Tags to attach to the resource. Array of maps, each of the form <code>string:string

         documented there.</p> |


#### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `destination_configuration` | String | <p>A complex type that contains a destination configuration for where chat content will be
         logged. There is only one type of destination (<code>cloudWatchLogs</code>,
            <code>firehose</code>, or <code>s3</code>) in a
         <code>destinationConfiguration</code>.</p> |
| `tags` | HashMap<String, String> | <p>Tags attached to the resource. Array of maps, each of the form <code>string:string
            (key:value)</code>.</p> |
| `state` | String | <p>The state of the logging configuration. When the state is <code>ACTIVE</code>, the
         configuration is ready to log chat content.</p> |
| `update_time` | String | <p>Time of the logging configuration’s last update. This is an ISO 8601 timestamp;
            <i>note that this is returned as a string</i>.</p> |

            <i>note that this is returned as a string</i>.</p> |
| `name` | String | <p>Logging-configuration name. This value does not need to be unique.</p> |
| `arn` | String | <p>Logging-configuration ARN, from the request (if <code>identifier</code> was an

         part of the ARN that uniquely identifies the logging configuration.</p> |

### Chat_token

ChatToken resource

**Operations**: ✅ Create

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `user_id` | String | ✅ | <p>Application-provided ID that uniquely identifies the user associated with this token.
         This can be any UTF-8 encoded text.</p> |
| `room_identifier` | String | ✅ | <p>Identifier of the room that the client is trying to access. Currently this must be an
         ARN. </p> |
| `capabilities` | Vec<String> |  | <p>Set of capabilities that the user is allowed to perform in the room. Default: None (the
         capability to view messages is implicitly included in all requests).</p> |
| `attributes` | HashMap<String, String> |  | <p>Application-provided attributes to encode into the token and attach to a chat session.
         Map keys and values can contain UTF-8 encoded text. The maximum length of this field is 1
         KB total.</p> |
| `session_duration_in_minutes` | i64 |  | <p>Session duration (in minutes), after which the session expires. Default: 60 (1
         hour).</p> |



#### Usage Example

```kcl
# main.k
import aws

# Initialize provider
provider = aws.AwsProvider {
    region = "us-east-1"
}

# Create chat_token
chat_token = provider.ivschat.Chat_token {
    user_id = "value"  # <p>Application-provided ID that uniquely identifies the user associated with this token.
         This can be any UTF-8 encoded text.</p>
    room_identifier = "value"  # <p>Identifier of the room that the client is trying to access. Currently this must be an
         ARN. </p>
}

```

```kcl

    region = "us-east-1"

}

    destination_configuration = "value-1"
}

    destination_configuration = "value-2"
}
```

### Conditional Creation

```kcl
# Only create in production
if environment == "production":
    logging_configuration = provider.ivschat.Logging_configuration {
        destination_configuration = "production-value"
    }
```

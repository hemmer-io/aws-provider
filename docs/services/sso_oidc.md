# Sso_oidc Service



**Resources**: 2

---

## Overview

The sso_oidc service provides access to 2 resource types:

- [Token](#token) [C]
- [Token_with_iam](#token_with_iam) [C]

---

## Resources


### Token

Token resource

**Operations**: ✅ Create

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `client_id` | String | ✅ | <p>The unique identifier string for the client or application. This value comes from the
      result of the <a>RegisterClient</a> API.</p> |
| `device_code` | String |  | <p>Used only when calling this API for the Device Code grant type. This short-lived code is
      used to identify this authorization request. This comes from the result of the <a>StartDeviceAuthorization</a> API.</p> |
| `client_secret` | String | ✅ | <p>A secret string generated for the client. This value should come from the persisted result
      of the <a>RegisterClient</a> API.</p> |
| `code_verifier` | String |  | <p>Used only when calling this API for the Authorization Code grant type. This value is
      generated by the client and presented to validate the original code challenge value the client
      passed at authorization time.</p> |
| `redirect_uri` | String |  | <p>Used only when calling this API for the Authorization Code grant type. This value
      specifies the location of the client or application that has registered to receive the
      authorization code.</p> |
| `code` | String |  | <p>Used only when calling this API for the Authorization Code grant type. The short-lived
      code is used to identify this authorization request.</p> |
| `scope` | Vec<String> |  | <p>The list of scopes for which authorization is requested. This parameter has no effect; the access token will always include all scopes configured during client registration.</p> |
| `grant_type` | String | ✅ | <p>Supports the following OAuth grant types: Authorization Code, Device Code, and Refresh
      Token. Specify one of the following values, depending on the grant type that you want:</p>
         <p>* Authorization Code - <code>authorization_code</code>
         </p>
         <p>* Device Code - <code>urn:ietf:params:oauth:grant-type:device_code</code>
         </p>
         <p>* Refresh Token - <code>refresh_token</code>
         </p> |
| `refresh_token` | String |  | <p>Used only when calling this API for the Refresh Token grant type. This token is used to
      refresh short-lived tokens, such as the access token, that might expire.</p>
         <p>For more information about the features and limitations of the current IAM Identity Center OIDC
      implementation, see <i>Considerations for Using this Guide</i> in the <a href="https://docs.aws.amazon.com/singlesignon/latest/OIDCAPIReference/Welcome.html">IAM Identity Center
        OIDC API Reference</a>.</p> |



#### Usage Example

```kcl
# main.k
import aws

# Initialize provider
provider = aws.AwsProvider {
    region = "us-east-1"
}

# Create token
token = provider.sso_oidc.Token {
    client_id = "value"  # <p>The unique identifier string for the client or application. This value comes from the
      result of the <a>RegisterClient</a> API.</p>
    client_secret = "value"  # <p>A secret string generated for the client. This value should come from the persisted result
      of the <a>RegisterClient</a> API.</p>
    grant_type = "value"  # <p>Supports the following OAuth grant types: Authorization Code, Device Code, and Refresh
      Token. Specify one of the following values, depending on the grant type that you want:</p>
         <p>* Authorization Code - <code>authorization_code</code>
         </p>
         <p>* Device Code - <code>urn:ietf:params:oauth:grant-type:device_code</code>
         </p>
         <p>* Refresh Token - <code>refresh_token</code>
         </p>
}

```

### Token_with_iam

TokenWithIAM resource

**Operations**: ✅ Create

#### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `code` | String |  | <p>Used only when calling this API for the Authorization Code grant type. This short-lived
      code is used to identify this authorization request. The code is obtained through a redirect
      from IAM Identity Center to a redirect URI persisted in the Authorization Code GrantOptions for the
      application.</p> |
| `subject_token_type` | String |  | <p>Used only when calling this API for the Token Exchange grant type. This value specifies
      the type of token that is passed as the subject of the exchange. The following value is
      supported:</p>
         <p>* Access Token - <code>urn:ietf:params:oauth:token-type:access_token</code>
         </p> |
| `redirect_uri` | String |  | <p>Used only when calling this API for the Authorization Code grant type. This value
      specifies the location of the client or application that has registered to receive the
      authorization code. </p> |
| `grant_type` | String | ✅ | <p>Supports the following OAuth grant types: Authorization Code, Refresh Token, JWT Bearer,
      and Token Exchange. Specify one of the following values, depending on the grant type that you
      want:</p>
         <p>* Authorization Code - <code>authorization_code</code>
         </p>
         <p>* Refresh Token - <code>refresh_token</code>
         </p>
         <p>* JWT Bearer - <code>urn:ietf:params:oauth:grant-type:jwt-bearer</code>
         </p>
         <p>* Token Exchange - <code>urn:ietf:params:oauth:grant-type:token-exchange</code>
         </p> |
| `subject_token` | String |  | <p>Used only when calling this API for the Token Exchange grant type. This value specifies
      the subject of the exchange. The value of the subject token must be an access token issued by
      IAM Identity Center to a different client or application. The access token must have authorized scopes that
      indicate the requested application as a target audience.</p> |
| `assertion` | String |  | <p>Used only when calling this API for the JWT Bearer grant type. This value specifies the
      JSON Web Token (JWT) issued by a trusted token issuer. To authorize a trusted token issuer,
      configure the JWT Bearer GrantOptions for the application.</p> |
| `scope` | Vec<String> |  | <p>The list of scopes for which authorization is requested. The access token that is issued
      is limited to the scopes that are granted. If the value is not specified, IAM Identity Center authorizes all
      scopes configured for the application, including the following default scopes:
        <code>openid</code>, <code>aws</code>, <code>sts:identity_context</code>.</p> |
| `requested_token_type` | String |  | <p>Used only when calling this API for the Token Exchange grant type. This value specifies
      the type of token that the requester can receive. The following values are supported:</p>
         <p>* Access Token - <code>urn:ietf:params:oauth:token-type:access_token</code>
         </p>
         <p>* Refresh Token - <code>urn:ietf:params:oauth:token-type:refresh_token</code>
         </p> |
| `code_verifier` | String |  | <p>Used only when calling this API for the Authorization Code grant type. This value is
      generated by the client and presented to validate the original code challenge value the client
      passed at authorization time.</p> |
| `refresh_token` | String |  | <p>Used only when calling this API for the Refresh Token grant type. This token is used to
      refresh short-lived tokens, such as the access token, that might expire.</p>
         <p>For more information about the features and limitations of the current IAM Identity Center OIDC
      implementation, see <i>Considerations for Using this Guide</i> in the <a href="https://docs.aws.amazon.com/singlesignon/latest/OIDCAPIReference/Welcome.html">IAM Identity Center
        OIDC API Reference</a>.</p> |
| `client_id` | String | ✅ | <p>The unique identifier string for the client or application. This value is an application
      ARN that has OAuth grants configured.</p> |



#### Usage Example

```kcl

    region = "us-east-1"

      and Token Exchange. Specify one of the following values, depending on the grant type that you
      want:</p>
         <p>* Authorization Code - <code>authorization_code</code>
         </p>
         <p>* Refresh Token - <code>refresh_token</code>
         </p>
         <p>* JWT Bearer - <code>urn:ietf:params:oauth:grant-type:jwt-bearer</code>
         </p>
         <p>* Token Exchange - <code>urn:ietf:params:oauth:grant-type:token-exchange</code>
         </p>
    client_id = "value"  # <p>The unique identifier string for the client or application. This value is an application
      ARN that has OAuth grants configured.</p>
}

```

## Common Operations

### Creating Multiple Resources

```kcl
import aws

provider = aws.AwsProvider {
    region = "us-east-1"
}

# Create multiple token resources
token_0 = provider.sso_oidc.Token {
    client_id = "value-0"
    client_secret = "value-0"
    grant_type = "value-0"
}
token_1 = provider.sso_oidc.Token {
    client_id = "value-1"
    client_secret = "value-1"
    grant_type = "value-1"
}
token_2 = provider.sso_oidc.Token {
    client_id = "value-2"
    client_secret = "value-2"
    grant_type = "value-2"
}
```

### Conditional Creation

```kcl
# Only create in production
if environment == "production":
    token = provider.sso_oidc.Token {
        client_id = "production-value"
        client_secret = "production-value"
        grant_type = "production-value"
    }
```
